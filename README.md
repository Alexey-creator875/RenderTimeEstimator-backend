# Расчет времени рендера 3D-сцены на рендер-ферме

REST API для публикации и просмотра конфигураций серверов рендеринга.

## HTTP методы

### GET http://localhost:8080/api/render-server-units

Возвращает список опубликованных услуг с количеством лайков и признаком `is_mine`. Можно отфильтровать по объёму ОЗУ через параметры `min` (по умолчанию 8) и `max` (по умолчанию 128); применённый диапазон возвращается в ответе. Ошибки: `400` — `min` или `max` не число, `500` — ошибка БД.

### GET http://localhost:8080/api/render-server-units/:id

Возвращает опубликованную услугу по ID с количеством лайков и признаком `is_liked`. Если передан параметр `next=true`, возвращает следующую после указанного ID услугу. Ошибки: `400` — некорректный `id` или `next`, `404` — запись не найдена или не опубликована, `500` — ошибка БД.

### GET http://localhost:8080/api/draft-render-server-units

Возвращает черновик текущего пользователя, а если его нет — `null` (это не ошибка). У пользователя может быть только один черновик. Ошибка: `500` — ошибка БД.

### POST http://localhost:8080/api/render-server-units

Создаёт черновик для текущего пользователя через `multipart/form-data`: обязательное поле `processor`, необязательные файлы `image` и `video`. Файлы сохраняются в MinIO, в БД пишутся только их имена. Возвращает `201`. Ошибки: `400` — форма не разобралась или файл неверного типа, `500` — ошибка БД или MinIO.

### PUT http://localhost:8080/api/render-server-units

Публикует черновик текущего пользователя и меняет статус на `published`. В `multipart/form-data` можно передать `cores`, `ram` и `description`; непереданные числа остаются прежними, описание становится пустым. Ошибки: `400` — `cores` или `ram` не число, `404` — черновика нет, `500` — ошибка БД.

### DELETE http://localhost:8080/api/render-server-units/:id

Мягко удаляет опубликованную услугу, созданную текущим пользователем: запись остаётся в БД, но помечается удалённой. Ошибки: `400` — некорректный `id`, `500` — ошибка БД.

### POST http://localhost:8080/api/render-server-units/:id/like

Ставит или снимает лайк текущего пользователя. В JSON-теле передаётся `like`: `true` — поставить (ответ `201`), `false` — снять (ответ `200`). Ошибки: `400` — некорректный `id` или тело, `500` — ошибка БД.

### POST http://localhost:8080/api/sign-up

Регистрирует пользователя по полям `login` и `password` (`multipart/form-data`), возвращает `201` с данными пользователя. Ошибка: `500` — ошибка БД.

### POST http://localhost:8080/api/sign-in

Заглушка авторизации: проверка логина и пароля не выполняется, возвращает `200` с сообщением.

### POST http://localhost:8080/api/sign-out

Заглушка деавторизации: никаких действий не выполняет, возвращает `200` с сообщением.

## Таблицы

### render_server_unit

| Поле | Тип | Комментарий |
|---|---|---|
| `id` | bigint | Автоматическое приращение |
| `status` | varchar(10) | `draft` или `published` |
| `processor` | varchar(30) | Модель процессора |
| `cores` | bigint | Количество ядер |
| `ram` | bigint | Объём ОЗУ, ГБ |
| `description` | varchar(300) | Описание |
| `image` | varchar(100) | Имя файла изображения в MinIO |
| `video` | varchar(100) | Имя файла видео в MinIO |
| `created_at` | timestamptz | Дата создания (auto) |
| `creator_id` | bigint | FK → `users.id` |
| `formed_at` | timestamptz | Дата последнего изменения (auto) |

### user

| Поле | Тип | Комментарий |
|---|---|---|
| `id` | bigint | Автоматическое приращение |
| `login` | varchar(40) | Логин |
| `password` | varchar(40) | Пароль |

### like

| Поле | Тип | Комментарий |
|---|---|---|
| `id` | bigint | Автоматическое приращение |
| `user_id` | bigint | FK → `users.id` — кто лайкнул |
| `render_server_unit_id` | bigint | FK → `render_server_units.id` — что лайкнул |
