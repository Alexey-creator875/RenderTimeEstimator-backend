# Расчет времени рендера 3D-сцены на рендер-ферме

REST API для публикации и просмотра конфигураций серверов рендеринга.

## HTTP методы

### GET http://localhost:8080/api/render-server-units

Возвращает список опубликованных услуг. Поддерживает фильтрацию по объёму ОЗУ через query-параметры `min` и `max`.

Для каждой услуги дополнительно считается:
- `likes_number` — общее количество лайков;
- `is_mine` — `true`, если услугу создал текущий пользователь, иначе `false`.

Query-параметры:

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `min` | int | `8` | Минимальный объём ОЗУ, ГБ |
| `max` | int | `128` | Максимальный объём ОЗУ, ГБ |

Ответ `200`:

```json
{
  "max": "128",
  "min": "8",
  "renderServerUnits": [
    {
      "id": 1,
      "processor": "RTX 2080 Ti",
      "description": "Надёжный выбор для рендеринга и игр. Отличная производительность в 2K и 4K, поддерживает все современные технологии трассировки лучей. Идеально для студийных проектов средней сложности.",
      "status": "published",
      "image": "http://localhost:9000/render-assets/2080-Ti.jpg",
      "video": "http://localhost:9000/render-assets/2080-Ti.mp4",
      "cores": 20,
      "ram": 16,
      "likes_number": 7,
      "is_mine": true
    }
  ]
}
```

Поля `min` и `max` дублируются в ответе, чтобы фронт знал, какой диапазон был применён (в том числе когда использовались значения по умолчанию).

Ошибки:

- `400` — `min` или `max` не число;
- `500` — ошибка БД.

---

### GET http://localhost:8080/api/render-server-units/:id

Возвращает одну опубликованную услугу по ID. Дополнительно считается количество лайков.

Query-параметры:

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `next` | string | — | Если `true` — вернуть не саму услугу, а **следующую** после указанного ID (для навигации). Иначе — услугу с указанным ID |

Ответ `200`:

```json
{
  "renderServerUnit": {
    "id": 1,
    "status": "published",
    "processor": "Intel Xeon E5-2699",
    "cores": 32,
    "ram": 128,
    "description": "Рендер-ферма под Blender",
    "image": "1_image.png",
    "video": "1_video.mp4",
    "created_at": "2025-01-15T10:00:00Z",
    "creator_id": 1,
    "formed_at": "2025-01-15T10:00:00Z",
    "likes_number": 42
  }
}
```

Ошибки:

- `400` — `id` не число; `next` передан, но не `true`;
- `404` — запись не найдена или не опубликована;
- `500` — ошибка БД.

---

### GET http://localhost:8080/api/draft-render-server-units

Возвращает черновик текущего пользователя. ID в запросе не указывается — пользователь определяется по аутентификации. У пользователя не может быть больше одного черновика.

Ответ `200`, если черновик есть:

```json
{
  "renderServerUnit": {
    "id": 7,
    "status": "draft",
    "processor": "AMD EPYC 7543",
    "cores": 16,
    "ram": 64,
    "description": "Черновик под Kubernetes",
    "image": "7_image.png",
    "video": "7_video.mp4",
    "created_at": "2025-01-15T10:00:00Z",
    "creator_id": 1,
    "formed_at": "2025-01-15T10:05:00Z"
  }
}
```

Ответ `200`, если черновика нет:

```json
{
  "renderServerUnit": null
}
```

Отсутствие черновика — нормальное состояние, а не ошибка: у только что зарегистрированного пользователя черновика ещё нет.

Ошибки:

- `500` — ошибка БД.

---

### POST http://localhost:8080/api/render-server-units

Создаёт черновик услуги для текущего пользователя. Изображение и короткое видео передаются **как файлы** (`multipart/form-data`), а не как URL. Имена файлов генерируются на латинице, сами файлы сохраняются в MinIO, а в БД пишутся только имена.

У пользователя не может быть больше одного черновика.

Content-Type: `multipart/form-data`.

Поля формы:

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `processor` | string | да | Модель процессора |
| `image` | file | нет | Изображение (`image/jpeg`, `image/png`, `image/gif`, `image/webp`) |
| `video` | file | нет | Короткое видео (`video/mp4`, `video/webm`, `video/quicktime`) |

Ответ `201`:

```json
{
  "renderServerUnit": {
    "id": 7,
    "status": "draft",
    "processor": "AMD EPYC 7543",
    "cores": 0,
    "ram": 0,
    "description": "",
    "image": "7_image.png",
    "video": "7_video.mp4",
    "created_at": "2025-01-15T10:00:00Z",
    "creator_id": 1,
    "formed_at": "2025-01-15T10:00:00Z"
  },
  "message": "Черновик успешно добавлен"
}
```

Ошибки:

- `400` — форма не парсится; файл не того типа (например, не изображение в поле `image` или не видео в поле `video`);
- `500` — ошибка БД или MinIO.

---

### PUT http://localhost:8080/api/render-server-units

Публикует черновик текущего пользователя. Меняет статус на `published` и заполняет оставшиеся поля: `cores`, `ram`, `description`. ID не передаётся — публикуется черновик текущего пользователя.

Content-Type: `multipart/form-data`.

Поля формы:

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `cores` | int | нет | Количество ядер. Если не передано — остаётся прежнее значение |
| `ram` | int | нет | Объём ОЗУ, ГБ. Если не передано — остаётся прежнее значение |
| `description` | string | нет | Описание. Если не передано — сохраняется пустая строка |

Ответ `200`:

```json
{
  "renderServerUnit": {
    "id": 7,
    "status": "published",
    "processor": "AMD EPYC 7543",
    "cores": 32,
    "ram": 128,
    "description": "Рендер-ферма под Blender",
    "image": "7_image.png",
    "video": "7_video.mp4",
    "created_at": "2025-01-15T10:00:00Z",
    "creator_id": 1,
    "formed_at": "2025-01-15T10:30:00Z"
  },
  "message": "запись успешно обновлена"
}
```

Ошибки:

- `400` — `cores` или `ram` не число;
- `404` — черновика у пользователя нет;
- `500` — ошибка БД.

---

### DELETE http://localhost:8080/api/render-server-units/:id

Удаляет услугу (soft delete). Физически запись остаётся в БД, но помечается удалённой. Удалить можно только **опубликованную** услугу, созданную текущим пользователем.

Ответ `200`:

```json
{
  "message": "запись успешно удалена"
}
```

Ошибки:

- `400` — `id` не число;
- `500` — ошибка БД.

---

### POST http://localhost:8080/api/render-server-units/:id/like

Ставит или снимает лайк от текущего пользователя на указанную услугу.

Content-Type: `application/json`.

Тело:

```json
{ "like": true }
```

| Значение | Действие |
|---|---|
| `true` | Поставить лайк (если ещё не стоит) |
| `false` | Снять лайк (если стоит) |

Ответ `201` — лайк поставлен:

```json
{ "message": "лайк поставлен" }
```

Ответ `200` — лайк отменён:

```json
{ "message": "лайк отменён" }
```

Ошибки:

- `400` — `id` не число; тело не парсится;
- `500` — ошибка БД.

---

### POST http://localhost:8080/api/sign-up

Регистрирует нового пользователя.

Content-Type: `multipart/form-data`.

Поля формы: 

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `login` | string | да | Логин |
| `password` | string | да | Пароль |

Ответ `201`:

```json
{
  "user": {
    "id": 1,
    "login": "alice",
  }
}
```

Ошибки:

- `500` — ошибка БД.

---

### POST http://localhost:8080/api/sign-in

Аутентификация пользователя. Заглушка для 4-й лабораторной — сейчас просто возвращает сообщение, никакой проверки логина и пароля не выполняет.

Ответ `200`:

```json
{ "message": "авторизация" }
```

---

### POST http://localhost:8080/api/sign-out

Деавторизация пользователя. Заглушка для 4-й лабораторной — сейчас просто возвращает сообщение, никаких действий не выполняет.

Ответ `200`:

```json
{ "message": "деавторизация" }
```

## Таблицы

### render_server_unit

| Поле | Тип | Комментарий |
|---|---|---|
| `id` | bigint | Автоматическое приращение |
| `status` | varchar(10) | `draft` или `published` |
| `processor` | varchar(30) | Модель процессора |
| `cores` | bigint | Количество ядер |
| `ram` | bigint | Объём ОЗУ, ГБ |
| `description` | varchar(300) | Описание |
| `image` | varchar(100) | Имя файла изображения в MinIO |
| `video` | varchar(100) | Имя файла видео в MinIO |
| `created_at` | timestamptz | Дата создания (auto) |
| `creator_id` | bigint | FK → `users.id` |
| `formed_at` | timestamptz | Дата последнего изменения (auto) |

### user

| Поле | Тип | Комментарий |
|---|---|---|
| `id` | bigint | Автоматическое приращение |
| `login` | varchar(40) | Логин |
| `password` | varchar(40) | Пароль |

### like

| Поле | Тип | Комментарий |
|---|---|---|
| `id` | bigint | Автоматическое приращение |
| `user_id` | bigint | FK → `users.id` — кто лайкнул |
| `render_server_unit_id` | bigint | FK → `render_server_units.id` — что лайкнул |
